# PRD：避坑型智能行程规划器（P0）

> 版本：1.0 ｜ 状态：P0 实施中 ｜ 分支：feature/p0-pitfall-planner

## 一、产品定位

**一句话**：基于抖音真实评论数据的避坑型智能行程规划器——不只告诉你"哪里好玩"，更告诉你"哪里会踩坑、坑长什么样、是谁踩的"。

从"景点信息报告生成器"升级为"行程决策引擎"：输入目的地/天数/预算/偏好，输出逐日分时段路书、预算明细、避坑专题、实时热度榜，全部信息带来源可溯。

## 二、目标用户

- 出发前 1~2 周做功课的自由行游客：厌倦了千篇一律的官方攻略，想要"真人踩过的坑"；
- 对营销软文有戒备心的用户：需要可验证的来源（视频链接 + 评论原文引用）；
- 预算敏感型旅行者：需要门票/餐饮/交通的花费预估与超支预警。

## 三、核心差异化（护城河）

| 差异化 | 实现方式 | 竞品现状 |
|---|---|---|
| 评论区避坑提取 | 高赞评论 → 立场评价（推荐/避雷/中性）→ 避坑专题附**评论原文引用** | 通用大模型只能给模板化"注意安全" |
| 实时热度分析 | 视频发布时间/点赞/评论密度 → 热度指数与趋势 | 静态攻略无法反映"最近突然火了" |
| 来源可追溯 | 每条要点带视频链接与置信度分级（多源一致/单源/存分歧） | 无来源或来源不可点验 |

## 四、输入输出规格

### 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| city | 是 | 目的地城市 |
| days | 是 | 出行天数（1~7） |
| hotel | 否 | 酒店/住宿位置（用于排线起点） |
| budget | 否 | 总预算（元，不含大交通）；提供时启用预算控制编排 |
| preference_mode | 否 | 省钱优先 / 体验优先 / 均衡（默认） |
| spots | 否 | 指定景点清单；缺省时走混合候选生成 |
| preferences | 否 | 自由文本偏好（如"带老人、喜欢历史"） |

### 输出结构

```
行程路书（Markdown + HTML 双格式）
├── 每日时间线：上午/下午/晚上 × {景点, 时长, 交通, 花费, 值得去, 避坑引用}
├── 预算明细：门票 / 餐饮 / 市内交通 / 弹性(10%) → 总计对比用户预算，超支给建议
├── 避坑专题：避雷要点 × {评论原文引用, 来源视频, 置信度}，多源一致排前
├── 热度榜：候选景点热度指数与趋势（近期热度上升/平稳）
└── 来源清单：全部视频链接
```

## 五、功能范围（P0）

1. **混合候选生成**：大模型生成 15~20 个候选（景点/美食/体验/购物四类）→ 抖音验证采集（每候选 5 视频 × 100 评论上限）→ 交叉验证筛选出 8~12 个优质候选。营销号视频（文案含团购/推广/合作/探店/点击左下角等）不参与评分。
2. **智能行程编排**：验证后的候选按地理聚类（高德，无 Key 降级）、时段匹配、预算控制排线。
3. **避坑与热度分析**：见差异化表；每条避坑提示必附评论原文引用（匿名化：去标识化闸口已保证无昵称等个人信息，引用截断 80 字）。
4. **HTML 可视化**：Jinja2 模板 + ECharts 预算饼图 + Leaflet 地图标注，离线降级不白屏。

### 数据能力基线（纠偏说明）

- 采集内容 = 视频文案 + 口播转写（ASR，可选）+ 高赞评论；本 P0 候选验证按 fast 档（文案+评论），评论为核心数据源；
- 评论上限 100 条/视频（频控与去标识化设计不变）；
- 商家结构化信息（人均/评分/营业时间）：有高德 Key 用 POI 数据，否则用评论提取值（标注"评论估算"），均无时由大模型基线知识补充并强制标注"未验证"。

## 六、验收标准

1. 大同 2 天 + 预算 1500 端到端跑通：输出含预算明细与超支/结余结论；
2. 避坑专题每条均有评论原文引用与来源视频链接；
3. 热度榜至少覆盖 3 个候选，指数可解释（三因子）；
4. HTML 报告在浏览器打开：时间线/饼图/地图/避坑高亮四板块齐全，断网时降级为文本版；
5. 离线测试全绿，不新增合规风险（频控、匿名引用、登录墙不穿透）。

## 七、路线图（本轮不做）

- **P1**：爬取并发优化与成本控制、小红书适配器（统一数据源接口）、README 全面重写、Streamlit Demo、宣传物料；
- **P2**：用户反馈多轮调整行程、PDF/长图导出。

## 八、合规底线（不可妥协）

频控保守（2.5~5 秒随机间隔）、评论去标识化、匿名引用、不破解签名不绕风控、采集专用小号、报告分析引用不搬运分发。
